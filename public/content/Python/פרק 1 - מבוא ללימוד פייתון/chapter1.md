# מבוא ללימוד פייתון

## מהי שפת סקריפטים?

ברוכים הבאים לשפת פייתון! שפת פייתון היא שפה שימושית וקלה לשימוש. לאחר שתשלטו בבסיס השפה תוכלו לכתוב תוכניות מסובכות בקלות יחסית. לדוגמה, במספר שורות קוד תוכלו לגרום לשני מחשבים לשלוח הודעות אחד לשני. בפחות ממאתיים שורות קוד תוכלו לפתח משחק מחשב, עם גרפיקה וצלילים.

שפת פייתון פותחה ב־1990 כשפת סקריפטים. כדי להבין מהי שפת סקריפטים, נבין קודם כיצד עובדת שפה שאינה שפת סקריפטים, לדוגמה שפת C.

כל שפת תוכנה צריכה להפוך בדרך כלשהי לשפת מכונה, כדי שהמעבד יוכל להריץ אותה. ההבדל בין שפת סקריפטים לשפה שאינה שפת סקריפטים הוא במסלול שעובר הקוד עד שהוא הופך לשפת מכונה.

קוד שנכתב בשפת C עובר שני שלבים:

1. **קומפילציה** – מתבצעת על ידי תוכנה שנקראת Compiler. הקומפיילר ממיר את הקוד משפת C לשפת Assembly.
2. **Assembly** – מתבצע על ידי Assembler, שממיר את הקוד משפת Assembly לשפת מכונה.

בסוף התהליך נוצר קובץ הרצה, בדרך כלל בעל סיומת `.exe`, שמכיל את הפקודות כשהן מתורגמות לשפת מכונה.

אפשר לבחון את התהליך באמצעות קומפיילר מקוון, לדוגמה:

<https://www.tutorialspoint.com/compile_c_online.php>

נניח שבתוכנית C תקינה שמדפיסה `Hello World` נוסיף שורה חסרת משמעות:

```c
blablabla
```

כאשר ננסה לבצע קומפילציה נקבל שגיאה כגון:

```text
error: 'blablabla' undeclared (first use in this function)
```

לא נוכל להריץ את התוכנית כלל, גם אם השגיאה מופיעה אחרי פקודת ההדפסה, משום שהתהליך נכשל עוד לפני שנוצר קוד מכונה.

## פייתון וה־Interpreter

פייתון היא שפת סקריפטים. על סקריפט פייתון פועלת תוכנה שנקראת **Interpreter** – פרשן.

בניגוד לקומפיילר ואסמבלר, ה־Interpreter אינו יוצר קובץ Assembly ואינו יוצר קובץ הרצה. כל פקודה בפייתון מתורגמת בזמן הריצה. תוך כדי התהליך יכול להיווצר קובץ `.pyc` שמכיל Bytecode, אך זה אינו קוד מכונה שהמעבד יכול להריץ ישירות.

### שפת סקריפטים לעומת שפת C

![תרשים השוואה בין C לפייתון](images/page-02-image-03.jpeg)

נבחן את הקוד הבא בפייתון:

```python
print("Hello World")
blablabla
```

השורה הראשונה תתבצע ותדפיס:

```text
Hello World
```

לאחר מכן ה־Interpreter יגיע לשורה `blablabla`, יזהה שאינה תקינה ויעצור את הריצה עם שגיאה.

![פלט שגיאה בפייתון](images/page-03-image-01.jpeg)

המשמעות היא שבפייתון התוכנית יכולה לרוץ באופן תקין עד לנקודה שבה מתרחשת השגיאה, בניגוד ל־C שבה שגיאת קומפילציה יכולה למנוע את הרצת התוכנית כולה.

### יתרונות וחסרונות

פייתון נחשבת שפה נוחה וקלה ללמידה, והקוד בה בדרך כלל קצר יותר מקוד מקביל בשפת C.

עם זאת, לשפת C יש יתרונות:

- שגיאות תחביר רבות מתגלות כבר בזמן הקומפילציה.
- קוד C יכול לעבור אופטימיזציה לפני הריצה.
- תוכניות C עשויות לרוץ מהר יותר ולצרוך פחות זיכרון.

פייתון, לעומת זאת, מאפשרת להגיע במהירות לתוכניות עובדות ומציעה ספרייה רחבה מאוד של מודולים מוכנים למשימות כמו חישובים מתמטיים, גרפיקה, ניהול קבצים ועוד.

## מספרים בבסיסים שונים

אנחנו בני האדם משתמשים בדרך כלל בבסיס 10. מחשבים עובדים בבסיס 2, כלומר בינארי, שבו קיימות רק הספרות `0` ו־`1`.

מכיוון שקשה לבני אדם לקרוא רצפים ארוכים של ביטים, מקובל להשתמש גם בבסיס 16 – הקסדצימלי. כל ספרה הקסדצימלית מייצגת ארבע ספרות בינאריות.

![בדיחה על בינארי](images/page-05-image-01.jpeg)

לדוגמה, הרצף הבינארי:

```text
1011 0001 1000 0010
```

ניתן לכתוב בהקסדצימלי כך:

```text
B182
```

### כתיבה בפייתון

מספר בינארי נכתב עם התחילית `0b`:

```python
0b11
```

התוצאה היא:

```text
3
```

לדוגמה נוספת:

```python
0b111
```

התוצאה היא:

```text
7
```

מספר הקסדצימלי נכתב עם התחילית `0x`:

```python
0x1A
```

התוצאה היא:

```text
26
```

```python
0x2B
```

התוצאה היא:

```text
43
```

## הסימן `_` – קו תחתון

ב־Python Interpreter אפשר להשתמש בסימן `_` כדי לגשת לתוצאה האחרונה שחושבה.

לדוגמה, נגדיר ערכים למשתנים `a` ו־`b` ונחשב:

```python
4 * (a + b) + 3
```

כעת אם רוצים להעלות את התוצאה בריבוע, אין צורך לכתוב שוב את כל הביטוי. אפשר לכתוב:

```python
_ ** 2
```

הסימן `_` אומר: **קח את התוצאה האחרונה שחישבת**.

> הטריק הזה עובד ב־Interpreter, אך לא בהכרח בסביבת העבודה שבה נשתמש בהמשך.

## הרצת תוכניות פייתון דרך ה־Command Line

כעת נכתוב את תוכנית הפייתון הראשונה שלנו.

אפשר להשתמש בעורך כמו Notepad או Notepad++.

שמרו את הקובץ עם סיומת `.py`, לדוגמה:

```text
hello.py
```

כתבו בתוכו:

```python
print("Hello cool cyber student!")
```

כדי להריץ את הקובץ משורת הפקודה, עברו תחילה לתיקייה שבה הוא נמצא.

לדוגמה:

```text
cd c:\
cd cyber
```

לאחר מכן הריצו:

```text
python hello.py
```

הקובץ יורץ מיד.
