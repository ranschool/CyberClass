# סביבת עבודה Visual Studio code

עד כה למדנו איך כותבים פקודות בסיסיות בחלון שורת הפקודה (Command Line) או באמצעות קובץ שכתבנו ב־Notepad++.

מה שעשינו נחמד בתור התחלה, אבל קשה מאוד לכתוב תוכניות משמעותיות בצורה זו. חסרה לנו סביבת עבודה שמאפשרת להריץ את הקוד מתוך הסביבה וכוללת דיבאגר. הכוונה בדיבאגר היא תוכנה שמסוגלת להריץ את הקוד שלנו פקודה אחרי פקודה, תוך כדי הצגת ערכי המשתנים השונים. זו יכולת קריטית כשרוצים להבין מדוע תוכנית שכתבנו לא עובדת באופן תקין.

בחרנו להציג בפניכם את סביבת העבודה **PyCharm**. היכולות שסביבת עבודה זו מעניקה לנו הן:

- **כתבן** – תחליף ל־Notepad++.
- **איתור שגיאות אוטומטי** – PyCharm מוצא עבורנו שגיאות בקוד, למשל אם שכחנו נקודתיים או השתמשנו במשתנה שלא קיבל ערך התחלתי. אין הכוונה לכך שהוא מתקן עבורנו באגים באלגוריתם.
- **דיבאגר** – יכולת להריץ את הקוד פקודה אחר פקודה (Step by Step), תוך הצגת ערכי המשתנים.
- **יכולת לאתחל בקלות תוכנית לאחר קריסה או באג** – במקום לאתחל את התוכנה, ניתן פשוט להורות ל־PyCharm להריץ אותה שוב.

כעת נלמד להשתמש בסביבת העבודה PyCharm.

## קובץ הפייתון הראשון שלנו

נסקור את השורות בקובץ הפייתון הראשון שלנו:

```python
def main():
    print("Hello cool cyber class!")


if __name__ == "__main__":
    main()
```

![הקובץ הראשון ב-PyCharm](assets/page_03_img_01.jpeg)

בשורה 1 מוגדרת פונקציה בשם `main`. כפי שברור מהשם שלה, זו הפונקציה הראשית של התוכנית שלנו. המשמעות היא שזו הפונקציה הראשונה שנקראת, ולכן כל מה שאנחנו רוצים שיבוצע צריך להיות כתוב בתוך `main`, או לחלופין ש־`main` תקרא לו.

![פונקציית main](assets/page_03_img_02.jpeg)

בשורה 5 יש תנאי מעט מסובך, שבהמשך הלימוד נבין מה פירושו. בקצרה – אנחנו יכולים להריץ סקריפט פייתון בשתי צורות:

1. פשוט להריץ אותו.
2. להריץ סקריפט אחר שקורא לסקריפט שלנו בעזרת הפקודה `import`.

נניח שכתבנו סקריפט פייתון שמכיל כמה פונקציות מעניינות, וחבר שלנו רוצה להשתמש בהן. אם החבר יקרא לסקריפט שלנו באמצעות `import`, עלול להיווצר מצב שבו כל הקוד שכתבנו ירוץ. כלומר, במקום שהתוכנית שלו פשוט תכיר את הפונקציות שלנו ותוכל לקרוא להן, התוכנית של החבר פשוט תפעיל את כל התוכנית שלנו. זה כמובן לא מצב רצוי.

לכן אנחנו מוסיפים את התנאי:

```python
if __name__ == "__main__":
    main()
```

המשמעות: קודם בודקים אם הסקריפט הורץ ישירות ולא באמצעות `import`. רק במקרה כזה קוראים לפונקציה `main` ומתחילים את ריצת הסקריפט.

## סדר ההרצה של פקודות בסקריפט פייתון

התבוננו שוב בסקריפט `hello.py`. מה יהיה סדר ההרצה של הפקודות? כלומר, איזו פקודה תרוץ ראשונה?

ה־interpreter של פייתון, שתפקידו לתרגם את פקודות הפייתון לשפת מכונה, מחפש את הפקודה הראשונה שצמודה לצד שמאל ואז בודק אם לא מדובר בהגדרה של פונקציה.

לכן, בשורה מספר 1 פייתון לומד שישנה פונקציה בשם `main`. פייתון מוסיף את `main` לרשימת הפונקציות המוכרות לו. כלומר, בשלב זה אפשר לקרוא ל־`main`, אך אין זה אומר שפייתון מריץ את `main` או אפילו בודק שהקוד של `main` תקין. כל מה שידוע לפייתון הוא שישנה פונקציה בשם `main`.

רק בשורה 5 נתקל פייתון בפקודה שעליו להריץ ושמבצעת משהו. אם התנאי בשורה מתקיים, פייתון ממשיך לשורה 6, ושם נאמר לו להריץ את הפונקציה `main`. בשלב זה פייתון קופץ אל `main` ומתחיל לבצע את מה שנכתב בה.

מאידך, אם התנאי שבשורה 5 אינו מתקיים, פייתון הגיע לסוף הסקריפט וריצת הסקריפט מסתיימת.

כעת שימו לב לסקריפט הבא – מה יהיה סדר הפקודות שיבוצע?

> שימו לב: זו אינה תוכנית פייתון הגיונית, וצורת הכתיבה של הקוד אינה משקפת צורת כתיבה מומלצת. מטרת הקוד היא רק להמחיש את סדר שלבי ריצת סקריפט הפייתון. נכון יותר היה לכתוב את כל פקודות ההדפסה בתוך פונקציית `main`.

```python
print("You say ", end="")


def main():
    print("Hello")


print("Goodbye")

if __name__ == "__main__":
    print("I say ", end="")
    main()
```

שורה 1 תדפיס למסך את הטקסט `You say `. מדוע כתוב `end=""`? בלי זה, לאחר `print` תבוצע ירידת שורה. מה שאנחנו רוצים הוא שלאחר ההדפסה יהיה תו אחד של רווח.

לאחר מכן תבוצע פקודת ההדפסה `Goodbye`, עם ירידת שורה בסופה.

בעקבות התקיימות התנאי `if __name__ == "__main__":`, תודפס המחרוזת `I say ` ולאחר מכן תתבצע קריאה לפונקציה `main`, שבתוכה יודפס `Hello`.

לאחר שהפונקציה `main` תסיים את ריצתה, היא תחזור לנקודה שממנה נקראה. מאחר שזו סוף התוכנית, בכך הסקריפט יסיים את ריצתו.

פלט התוכנית:

```text
You say Goodbye
I say Hello
```

## קביעת פרשן (Interpreter)

סביבת ההתקנות אמורה להתקין ולאפשר עבודה מיידית בלי צורך בהגדרות נוספות. אולם אם מופיעה שגיאה מסוג:


צריך להגדיר ל־PyCharm היכן ניתן למצוא את ה־interpreter של שפת פייתון. זאת מכיוון שיש גרסאות שונות של פייתון, וייתכן שעל אותו מחשב מותקנות כמה גרסאות שונות.

## הרצת הסקריפט ומסך המשתמש

כדי להריץ את הסקריפט שכתבנו, נלחץ על עכבר ימני ונבחר באפשרות **Run**.

![הרצת הסקריפט](assets/page_09_img_01.jpeg)

בעקבות הלחיצה על `Run` יופיע מסך משתמש, שם יודפס כל מה שהסקריפט שלנו מדפיס למסך.

![חלון הפלט](assets/page_09_img_02.jpeg)

מסך המשתמש משמש גם לקבלת קלט מהמשתמש. שימו לב לפקודה `input`:

```python
def main():
    name = input("Please enter your name: ")
    print("Hello " + name)


if __name__ == "__main__":
    main()
```

פקודה זו מדפיסה למסך את מה שנמצא בסוגריים, וכל מה שהמשתמש מקליד נכנס לתוך משתנה, במקרה זה `name`.

בשורה הבאה מתבצעת הדפסה של `Hello` ולאחר מכן הערך שנמצא בתוך המשתנה `name`.

![קלט מהמשתמש באמצעות input](assets/page_10_img_01.jpeg)

## דיבוג עם PyCharm

כאמור, אחת היכולות המשמעותיות של PyCharm היא האפשרות לדבג קוד. כיצד עושים זאת?

בשלב הראשון יש לשתול **breakpoint** בקוד. דבר זה מתבצע על ידי לחיצה שמאלית באזור האפור שליד מספרי השורות. בעקבות כך תופיע נקודה אדומה ליד מספר השורה.

![הוספת breakpoint](assets/page_11_img_01.jpeg)

בשלב הבא צריך להריץ את התוכנית במצב **Debug**, על ידי קליק ימני ובחירת האפשרות `Debug`.

![הרצה במצב Debug](assets/page_11_img_02.jpeg)

לאחר מכן נראה כי התרחשו כמה דברים:

1. התוכנית רצה עד לשורה עם הנקודה האדומה – ה־breakpoint – ושם עצרה.
2. השורה סומנה בכחול.
3. נפתח חלון ה־debugger, אשר מכיל מידע על המשתנים שמוגדרים בתוכנית שלנו.

לדוגמה, המשתנה `name` הוא מסוג `str` וערכו הוא `Shooki`, הערך שהמשתמש הזין לתוכו. ניתן לראות את הערך של `name` בחלון ה־Variables.

![חלון Variables בדיבאגר](assets/page_12_img_01.jpeg)

לחיצה על לשונית **Console** תעביר אותנו אל מסך המשתמש (קלט/פלט).

![לשונית Console](assets/page_12_img_02.jpeg)

נחזור אל חלון הדיבאגר. כפי שניתן לראות ישנם חיצים מסוגים שונים. לחיצה על החיצים תקדם את התוכנית שלנו. אם נעמוד עם העכבר על חץ כלשהו יופיע כיתוב שמסביר מה החץ עושה.

בשלב זה מומלץ להשתמש ב־**Step Over**, השמאלי ביותר. נוח מאוד להשתמש בקיצור המקלדת שלו – `F8`. חץ זה מריץ שורת קוד אחת בכל פעם, שורה אחר שורה.

כאשר נכתוב פונקציות, נרצה להשתמש לעיתים קרובות גם ב־**Step Into**. קיצור המקלדת שלו הוא `F7`.

אם נרצה להפסיק את הדיבוג, או להתחילו מחדש, נוכל להשתמש בלחצנים מצד שמאל של חלון הדיבאגר.

מומלץ לשלוט בפעולות אלו, מכיוון שבבוא העת שימוש נכון בהן יאפשר לכם לגלות בקלות בעיות בתוכנה שלכם.

## העברת פרמטרים לסקריפט

> דלגו על החלק הזה, וחיזרו אליו רק לאחר שתלמדו על `sys.argv`.

כדי להעביר פרמטרים לסקריפט, כלומר מידע שהמשתמש מעביר לסקריפט לפני תחילת הריצה (לדוגמה, שם של קובץ שהסקריפט צריך לעשות בו שימוש), נקליק על שם הקובץ שנמצא מצד ימין למעלה, ואז נבחר **Edit Configurations**.

כעת ייפתח מסך ובו ניתן לקבוע **Script Parameters**. ניתן להזין לתוכו כמה פרמטרים שנרצה, עם סימן רווח בין פרמטר אחד לשני.
