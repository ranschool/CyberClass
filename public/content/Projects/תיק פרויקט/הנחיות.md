## חלופה: הגנת סייבר ומערכות הפעלה

במסגרת לימודי ההתמחות בתכנון ותכנות מערכות (הנדסת תוכנה) – 883589

תיק הפרויקט הוא חלק מרכזי בעבודת הגמר בהנדסת תוכנה. מטרתו לתעד בצורה ברורה, מסודרת ומקצועית את תהליך העבודה על הפרויקט, החל משלב הרעיון והתכנון ועד למימוש, לבדיקה ולהצגת המוצר הסופי.

תיק הפרויקט אינו מיועד רק להציג את התוצאה הסופית של העבודה, אלא גם להראות כיצד התלמיד תכנן את המערכת, אילו החלטות קיבל במהלך הפיתוח, באילו טכנולוגיות השתמש, אילו קשיים התעוררו וכיצד התמודד איתם.

המטרה היא ליצור מסמך אחיד וברור, כך שהתלמיד, המורה והבוחן יוכלו להבין מה מצופה להופיע בתיק הפרויקט ולנווט בו בקלות.

יש להקפיד לאורך כל העבודה על כתיבה ברורה, סדר לוגי, אחידות בעיצוב ושימוש נכון בכותרות.

# כותרת עליונה ותחתונה

בכל עמוד במסמך יש להשתמש בכותרת עליונה ובכותרת תחתונה.

## כותרת עליונה – Header

בכותרת העליונה יש להציג לפחות:

**שם התלמיד | שם הפרויקט**

לדוגמה:

**ישראל ישראלי | Secure Network Monitor**

ניתן להוסיף גם פרטים נוספים, כגון:

* שם בית הספר.
* שנת הלימודים.
* שם החלופה.

## כותרת תחתונה – Footer

בכותרת התחתונה יש להציג לפחות את:

**מספר העמוד**

ניתן להוסיף פרטים נוספים, אך יש לשמור על עיצוב נקי ולא עמוס.

## כיצד ליצור כותרת עליונה ותחתונה ב־Google Docs

### יצירת כותרת עליונה

1. פתחו את מסמך הפרויקט ב־Google Docs.
2. בתפריט העליון בחרו **הוספה**.
3. בחרו **כותרות עליונות ותחתונות**.
4. בחרו **כותרת עליונה**.
5. הקלידו את שם התלמיד ואת שם הפרויקט.

לדוגמה:

**ישראל ישראלי | Secure Network Monitor**

הכותרת תופיע באופן אוטומטי בכל עמודי המסמך.

### יצירת כותרת תחתונה

1. בתפריט העליון בחרו **הוספה**.
2. בחרו **כותרות עליונות ותחתונות**.
3. בחרו **כותרת תחתונה**.

### הוספת מספרי עמודים

אין צורך להקליד את מספרי העמודים באופן ידני.

כדי להוסיף מספור אוטומטי:

1. בחרו **הוספה**.
2. בחרו **מספרי עמודים**.
3. בחרו את צורת המספור הרצויה.

מומלץ לבחור באפשרות שבה מספר העמוד מופיע בחלק התחתון של הדף.

Google Docs יעדכן את מספרי העמודים באופן אוטומטי כאשר יתווספו או יימחקו עמודים מהמסמך.

### המלצה לגבי דף השער

מומלץ שלא להציג את הכותרת העליונה ואת מספר העמוד בדף השער.

ניתן לעשות זאת באמצעות האפשרות:

**Different first page / עמוד ראשון שונה**

בתפריט האפשרויות של הכותרת העליונה והתחתונה.

כך דף השער יישאר נקי, והכותרת והמספור יתחילו מהעמודים הבאים.

# שער

דף השער הוא העמוד הראשון של תיק הפרויקט והוא משמש להצגת הפרטים המרכזיים של העבודה.

דף השער יכלול:

1. לוגו בית הספר.
2. שם בית הספר.
3. שם הפרויקט.
4. שם התלמיד.
5. מספר תעודת הזהות של התלמיד.
6. שם המנחה.
7. שם החלופה: **הגנת סייבר ומערכות הפעלה**.
8. תאריך ההגשה.

ניתן לעצב את דף השער בצורה חופשית, כולל שימוש בצבעים, תמונות רקע או איורים הקשורים לנושא הפרויקט.

עם זאת, יש להקפיד שהשער יהיה:

* ברור.
* מקצועי.
* קריא.
* לא עמוס מדי.

מומלץ לתת לשם הפרויקט מקום מרכזי ובולט בדף.

# תוכן עניינים

תוכן העניינים צריך להיווצר **באופן אוטומטי באמצעות Google Docs**.

אין לכתוב את תוכן העניינים באופן ידני.

לשם כך יש להשתמש בסגנונות הכותרת המובנים במסמך:

* **כותרת 1 / Heading 1** – עבור פרקים ראשיים.
* **כותרת 2 / Heading 2** – עבור סעיפים בתוך פרק.
* **כותרת 3 / Heading 3** – עבור תתי־סעיפים.

לדוגמה:

**כותרת 1**
מבוא

**כותרת 2**
הגדרת הלקוח

**כותרת 3**
סוגי המשתמשים במערכת

## כיצד מגדירים כותרת ב־Google Docs

1. סמנו את הטקסט שאמור לשמש ככותרת.
2. בסרגל הכלים לחצו על התיבה שבה מופיע בדרך כלל **טקסט רגיל**.
3. בחרו:

   * כותרת 1
   * כותרת 2
   * כותרת 3

בהתאם לרמת הכותרת.

## כיצד יוצרים תוכן עניינים אוטומטי

1. מקמו את הסמן בעמוד שבו תרצו להציג את תוכן העניינים.
2. בחרו בתפריט **הוספה**.
3. בחרו **תוכן עניינים**.
4. בחרו את סגנון תוכן העניינים הרצוי.

Google Docs ייצור את תוכן העניינים בהתאם לכותרות שהוגדרו במסמך.

לאחר שבוצעו שינויים במסמך, יש לעדכן את תוכן העניינים באמצעות כפתור העדכון המופיע לידו.

לפני ההגשה יש לוודא שכל הכותרות ומספרי העמודים בתוכן העניינים נכונים.
