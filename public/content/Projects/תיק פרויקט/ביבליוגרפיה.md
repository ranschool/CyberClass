# ביבליוגרפיה

פרק הביבליוגרפיה מרכז את כל מקורות המידע שבהם נעשה שימוש במהלך תכנון, פיתוח וכתיבת הפרויקט.

מטרת הפרק היא להראות על אילו מקורות הסתמך התלמיד לצורך לימוד טכנולוגיות, פתרון בעיות, הבנת מושגים, בחירת אלגוריתמים, עבודה עם ספריות ותכנון המערכת.

יש לכלול רק מקורות שבאמת נעשה בהם שימוש במהלך העבודה.

---

# 1. אילו מקורות יש לכלול?

ניתן לכלול מקורות מסוגים שונים:

* תיעוד רשמי של שפות תכנות.
* תיעוד רשמי של ספריות.
* אתרי מידע מקצועיים.
* מאמרים.
* ספרים.
* מדריכים.
* סרטוני הדרכה.
* מאגרי קוד.
* פורומים מקצועיים.
* אתרי יצרנים.
* תיעוד של פרוטוקולים.
* מקורות בנושא אבטחת מידע.

לדוגמה:

* Python Documentation.
* Scapy Documentation.
* PyQt Documentation.
* SQLite Documentation.
* OWASP.
* RFC.
* GitHub Documentation.

---

# 2. עדיפות למקורות רשמיים

כאשר קיימת אפשרות, מומלץ להעדיף תיעוד רשמי.

לדוגמה, אם נעשה שימוש ב־Python, עדיף להסתמך על התיעוד הרשמי של Python ולא רק על אתר שמסביר Python באופן כללי.

באופן דומה:

* עבור Scapy – מומלץ להשתמש בתיעוד הרשמי של Scapy.
* עבור SQLite – בתיעוד הרשמי של SQLite.
* עבור Git – בתיעוד הרשמי של Git.
* עבור נושאי אבטחה – במקורות מקצועיים כמו OWASP.

מקור רשמי נחשב בדרך כלל אמין ומדויק יותר.

---

אין לכתוב רק את שם האתר.

לדוגמה, לא מספיק לכתוב:

```text
Google
YouTube
Wikipedia
ChatGPT
```

יש לציין את המקור בצורה ברורה ככל האפשר.

רישום של מקור אינטרנטי צריך לכלול בדרך כלל:

* שם המחבר או הארגון.
* שם העמוד או המסמך.
* שם האתר.
* קישור.
* תאריך גישה, אם נדרש.

# 7. תיעוד של ספריות בפרויקט

בפרויקט תוכנה סביר שהתלמיד יסתמך על תיעוד של מספר ספריות.

לדוגמה, בפרויקט Sniffer ניתן לכלול:

```text
Python Software Foundation. (n.d.). socket — Low-level networking interface.
Python Documentation.
https://docs.python.org/

Scapy Project. (n.d.). Scapy Documentation.
https://scapy.readthedocs.io/

Python Software Foundation. (n.d.). threading — Thread-based parallelism.
Python Documentation.
https://docs.python.org/
```

אין צורך להכניס כל ספרייה שמופיעה ב־`import`.

יש לכלול את הספריות או המקורות שבאמת שימשו ללמידה או לפיתוח.

# 12. כללי APA

לפי ההנחיות יש להציג את רשימת המקורות לפי כללי APA.

אין צורך להיכנס לרמת מחקר אקדמי מורכבת, אך יש לשמור על מבנה אחיד.

מבנה בסיסי למקור אינטרנטי:

```text
Author / Organization. (Year). Title.
Website.
URL
```

מבנה בסיסי לספר:

```text
Author. (Year). Book title.
Publisher.
```

העיקר הוא לשמור על אחידות לאורך כל הרשימה.
